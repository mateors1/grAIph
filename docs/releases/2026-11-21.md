# v0.4.0 Research Preview — November 21, 2026

This is a **documentation-only research preview** of the public teaser. The private engine, extension, raw provider logs, and internal benchmark inputs are not included. No installable product, production qualification, or private implementation release is declared.

## Retained evidence rechecked

The newest retained saved-graph regeneration receipt reviewed here completed on November 15. Its V59 run recorded:

- 53/53 generated units and 53/53 current-run provenance admissions in one native batch;
- no manual restart, runtime engine/settings change, re-import, or manual generated-code edit during that batch;
- 166 complete captured input/response pairs, with no recorded hash mismatch or body truncation;
- 5,437 passing tests, zero failures, and 35 skips for that frozen development source cut;
- the existing corrected-source/non-clean evaluation: 288/309 normalized differential cases and 9.49/10, confidence B.

The November 21 review rehashed the retained source, extension, and output inventories, checked the immutable input and receipt hashes, and independently compared graph intent, edges, and dependency contracts. The mutable runtime graph is expected to advance during generation; it is not treated as an immutable input file. No new inference or product test run was performed for this release.

These results were already recorded in the merged November update; this release adds the receipt recheck and clearer interpretation. Complete admissions are not semantic proof or universal source-leak resistance. Captured transport inputs are not served-backend attestations. The earlier incomplete and failed runs remain in the evidence history.

## Harness comparisons clarified

The later pilot exercised real Codex workspace tools and real grAIph generation, but used a custom direct profile and externally constrained graph planning/dispatch. It does not qualify an unrestricted full-harness comparison. The [comparison scope guide](../harness-comparison-scope.md) requires normal workspace editing, tool use, and verification, with the same prompts delivered one at a time. Code-only/file-snapshot trials remain historical controls.

## Release ceiling

The tested engine source cut contained uncommitted changes. Native packaging, hardware integration, Windows-native qualification, the complete visual-origin/performance matrix, and soak testing remain open. The fresh relation-surface A/B is still pending. An uninterrupted regeneration result does not establish production readiness or a general model, speed, or cost ranking.

The documentation release does not close those product gates. See [Current state](../../CURRENT_STATE.md), [Reading the evidence](../evidence-guide.md), and [Getting started](../getting-started.md).
